## 🚀 Setting up your first tournament

1. Double-click the desktop icon to open the program.
2. Select Create New Tournament from the main screen.
3. Type the name of your league.
4. Choose the type of sport you manage.
5. Press the Save button to start building your competition.
6. Use the Add Player button to enter names into the roster.
7. Click Generate Schedule when you finish adding players.
8. The program creates a list of games for the entire season.

## 📊 Managing matches and results

1. Navigate to the Matches tab in the sidebar.
2. Find the match you want to update.
3. Click the Enter Score button next to the match.
4. Input the final scores for each side.
5. Click Update to finalize the result. 
6. The Standings table updates immediately to reflect the new rank of each player or team.

## 🔍 Frequently asked questions

Do I need an internet connection to use the app?
No. You only need the internet to download the file. After installation, all features work offline.

Can I move my data to another computer?
Yes. Open the settings menu and select Export Data. Move this file to your other computer and use the Import Data option.

Does the software support different types of leagues?
Yes. You can organize single-elimination brackets or round-robin schedules.

What happens if I make a mistake while entering scores?
You can select any past match from the schedule list. Click the Edit button to correct the score and save the change. The software recalibrates the standings automatically.

How do I remove a player from the tournament?
Go to the Roster tab. Find the player name and click the Trash icon. The program removes the player and recalculates the schedule for remaining participants.

Is my data safe?
The program saves all information directly to your hard drive. No third party has access to your player records or match results.

## 🛠 Troubleshooting tips

If the program fails to open, restart your computer and try again. Ensure no other applications are blocking the installation process. If the buttons appear unresponsive, check your display resolution settings. High-resolution screens sometimes shrink buttons. You can adjust this in your Windows Display settings.

Regular updates keep the program working well. Check the download page every few months to see if a newer version exists. You can install a new version over the old one without losing your saved tournaments. Always back up your data folder before you install an update to be safe. You find this folder in your document directory under the name TournamentsApp. Copy this folder to a USB drive or cloud storage to keep an extra copy of your league history.
